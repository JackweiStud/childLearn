# 干净试卷重建

## 目标与硬约束

把做过的试卷变成可再次作答的打印稿。始终遵守以下优先级：

1. 题目、数字、单位、选项和图形准确。
2. 所有学生作答、姓名和教师批改彻底移除。
3. 打印清晰、排版一致、答题空间可用。
4. 版式接近原卷，但不为像素级相似牺牲内容准确性。

不要把“清除笔迹”默认理解为图片涂白。黑色笔迹与印刷内容重叠时，原像素已经丢失，必须重建被遮挡内容。

## 路线选择

按顺序选择处理路线：

1. **反查原卷**：用卷名、栏目名和独特题干搜索可核验的原始 PDF 或图片。找到后逐题对照用户照片，确认版本一致。
2. **图像清理**：仅当笔迹颜色与印刷内容可可靠分离，且没有覆盖题干、数字或图形时使用颜色分割、蒙版和修复。
3. **矢量重建**：当铅笔、黑笔或红笔覆盖印刷内容，或照片存在透视、阴影、折痕、透字时，重新录入文字并矢量绘制图形。这是默认推荐路线。
4. **待确认**：内容被遮挡且无法从上下文、原卷或其他页面确认时，不要猜。输出局部截图和待确认清单，请用户补拍或确认。

## 标准流程

### 运行依赖

- 使用 `reportlab` 生成矢量 PDF。
- 使用 `pypdf` 反向提取文字并检查字体。
- 使用 Poppler 的 `pdftoppm`、`pdfinfo` 渲染和检查 PDF。
- 优先调用 Codex 工作区自带的文档运行时；仅在依赖确实缺失时安装最小依赖。

### 1. 建立原始事实

- 统计照片对应的逻辑页数、正反面和页序。
- 旋转、裁边、透视校正并按单页拆分；保留未经修改的原图作为事实来源。
- 使用 OCR 提高录入效率，但只把 OCR 当候选文本。
- 对照原图逐题确认题号、标点、数字、单位、空格、选项和图形。
- 优先用两到四条独特题干反查原卷；检索不到时明确记录“未找到可核验原卷”。

### 2. 建立内容模型

按以下层级组织内容，不要直接在图片上反复涂改：

```text
试卷
├── 页面
│   ├── 关卡或大题
│   │   ├── 题目
│   │   │   ├── 小题
│   │   │   ├── 选项
│   │   │   ├── 图形
│   │   │   └── 答题区
```

给每条内容标记来源：原图清晰可见、原卷核验、上下文推断或待用户确认。只有前两类可以直接作为“已确认”内容。

### 3. 生成打印稿

- 默认输出单面 A4；用户明确要求时再生成 A3 双面或折叠版。
- 优先使用 ReportLab 等矢量 PDF 工具，不要用生成式图片承载中文题目。
- 嵌入中文字体和特殊符号字体，避免换电脑后出现方框字。
- 用表格或固定列宽完成选择题、判断题和并排小题；禁止依靠连续空格控制位置。
- 用矢量线条重绘钟表、方格、几何图形、按钮和答题框。
- 控制长题干换行，禁止姓名、单位、数字组合或句末两三个字孤立成行。

采用以下默认字号，并根据页数轻微调整：

- 主标题：18-19 pt
- 大题标题：14 pt
- 正文：11-11.5 pt
- 选项：10.5-11 pt
- 页脚：8 pt
- 公式方框、圆圈和三角形：14-15 pt
- 可填写矢量方框：边长至少 3 mm

生成 PDF 时，按需读取 [排版与绘图模式](references/layout-patterns.md)。

### 4. 执行闭环验收

每次重要修改后执行以下循环，不要只检查源代码：

```text
生成 PDF -> 渲染为 PNG -> 放大检查 -> 修复 -> 全页回归 -> 内容审计
```

检查受影响页面时使用 200-220 DPI；最终全卷使用 150-170 DPI 渲染。逐页检查：

- 题目与题目是否容易区分。
- 选项字号、列宽和水平间距是否一致。
- 方框、圆圈、钟面数字和刻度是否清晰。
- 是否存在裁切、重叠、孤行、拆词或答题空间不足。
- 修改一页后，其他页面是否发生分页或布局漂移。

使用通用校验脚本检查 PDF：

```bash
python3 scripts/validate_exam_pdf.py <试卷.pdf> \
  --expected-pages 4 \
  --required '综合素养通关' \
  --forbidden '学生姓名' \
  --render-dir /tmp/exam-render
```

交付前完整执行 [验收清单](references/acceptance-checklist.md)。

## 失败模式

禁止以下做法：

- 把 OCR 结果直接当成正确题干。
- 对黑色手写覆盖区直接 AI 擦除并声称已经恢复原文。
- 用生成式图片生成包含大量中文、数字或算式的试卷。
- 用连续空格排选择题、算式或并排小题。
- 使用默认字体中的微小 `□`、`○` 而不进行打印尺寸检查。
- 只验证 PDF 能打开，不把每页渲染成图片检查。
- 内容存在歧义时自行补全并标记为“准确”。

## 用户补拍要求

材料不足时，一次只提出最关键的补拍要求：

- 一页一张，正上方拍摄，四角完整。
- 长边建议至少 2000 像素。
- 避免反光、阴影、折叠和手指遮挡。
- 对被重度涂写的题目增加局部近照。
- 按页码顺序提供全部正反面。

## 交付格式

交付时提供：

1. 可打印 PDF。
2. 页数、纸张尺寸和字体嵌入检查结果。
3. 已完成的内容与版式验收摘要。
4. 未解决的歧义清单；若为空，明确写“无待确认项”。
5. 说明成品是原卷下载、图像清理还是矢量重建，不混淆三种来源。

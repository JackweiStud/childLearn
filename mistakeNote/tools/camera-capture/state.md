# camera-capture · 工具状态

> 本文档记录这个工具的核心诉求、功能拆解和进展。供后续开发时快速对齐上下文。

---

## 一、在 mistakeNote 中的位置

```
孩子做错题 → [拍照采集] → 识别/切题 → 归档到错题库 → 生成复习卷 → 孩子重做
              ▲
              本工具
```

camera-capture 是整条链的**第一环**——把纸上的试卷变成数字文件。它的下游是识别、裁剪、归档，最终产出物是给孩子做的复习卷。

**这个工具成功的标志**：家长拿到孩子批改完的试卷后，30 秒内完成拍照并存入系统，不需要任何额外操作。

---

## 二、核心诉求

把**纸质试卷/作业**变成**结构化的数字素材**，具体要解决：

1. **采集**——用摄像头把试卷拍下来，质量够后续识别用（清晰、不变形、曝光正常）
2. **标记**——拍照时能快速框出错题区域，省去后续人工定位（工具辅助手--框选或者选择截图）
3. **存储**——按日期自动归档，配对元数据 JSON，后续处理管线可直接消费
4. **来源多样**——USB 摄像头、iPhone（Continuity Camera）都要能用

### 与下游管线的对接点

camera-capture 的输出格式已经为下游准备好：

```
_inbox/scans/YYYY-MM-DD/YYYYMMDD-HHMMSS-usb-camera-001.jpg   ← 原始图
_inbox/scans/YYYY-MM-DD/YYYYMMDD-HHMMSS-usb-camera-001.json  ← 元数据
```

JSON 中 `status: 'unprocessed'` 表示还没被后续管线消费。下游处理完后应更新此状态。

## 六、技术栈与代码结构

- **运行时**：Node.js ≥ 20（纯 CommonJS，零依赖）
- **前端**：原生 HTML + JS + CSS，无框架、无构建
- **服务端**：`node:http` 手写路由
- **原生采集**：ffmpeg + AVFoundation（macOS）
- **端口**：`http://localhost:8731`

### 前端模块化结构（v2 重构后）

```
src/public/
├── index.html              # 页面结构：左工具栏 | 中预览 | 右设置+最近 | 底部日志
├── styles.css              # 全局样式：暖色调产品级 UI，响应式布局
├── ui.js                   # DOM 引用缓存、日志面板、状态提示
├── camera-handler.js       # 统一摄像头管理：WebRTC/native 切换、设备检测、画质调节、拍照
├── annotation-handler.js   # 标注工具：矩形/圆形/画笔/擦除/截图/撤销/颜色
├── recent-handler.js       # 最近拍摄列表、双击打开大图、Finder 目录打开
├── capture-effects.js      # 软件滤镜参数定义与 CSS filter 转换（UMD，Node 可测试）
└── app.js                  # 主调度器：模块初始化、事件绑定、定时检测循环
```

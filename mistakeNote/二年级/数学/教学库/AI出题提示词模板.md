## 模板一：新题型入门动画（第一次遇到某类题）

**使用时机**：孩子第一次碰到某类题型，还没卡，提前建立直觉。

```
我孩子二年级，第一次遇到【题型，如：送出倒推型/比较差值型/总量求部分型】应用题。

请帮我设计一个**分步骤的动画说明**，用于给孩子讲解这类题的核心思路。

要求：
1. 用具体的故事情境（人物+实物），不要抽象符号
2. 分成3-4个步骤，每个步骤只发生一件事
3. 每个步骤配一句"旁白"，语言像在跟孩子说话
4. 在第2步之前加一句"你猜接下来会发生什么？"让孩子先预测
5. 最后一步让孩子自己列算式

示例题目：【粘贴原题】
```

## 模板二：卡题攻坚（孩子已经卡住了）

**使用时机**：孩子卡题超过3分钟，执行卡Step 3还没解决。

```
我孩子二年级，卡在这道题上：

【粘贴原题】

他现在的错误想法是：【描述孩子的错法，如"他把35直接减18"/"他不理解为什么要乘2"】

请帮我：
1. 用**实物摆放的步骤**描述怎么用积木/硬币演示这道题（每步一句话）
2. 每步演示前给我一个"问孩子的问题"，让他先预测
3. 演示完后给我2个问题，让孩子用自己的话解释刚才发生了什么
4. 最后给1道同类型但数字更小的题，让他立刻验证自己懂了

不要直接告诉他答案和公式。
```

## 模板三：交错变体练习（巩固用）

**使用时机**：孩子当天理解了某类题，需要出练习题。

```
我孩子二年级，今天刚理解了【题型，如：送出倒推型】应用题。

请出3道练习题，要求：
1. 第1道：同类型（送出倒推），换人物和数字，难度相当
2. 第2道：【另一个题型，如：比较差值型】，难度相当——交错练习
3. 第3道：【再一个题型，如：总量求部分型】，难度相当——交错练习

每道题格式：
- 题目（故事情境，人物用孩子熟悉的名字如"小明/小红"）
- 给家长的提示：这题的卡点在哪，孩子容易错在哪

数字范围：100以内，不涉及乘除。
```

## 模板四：D+3复测题（3天后验收）

**使用时机**：3天前孩子理解了某类题，今天随口测一次。

```
3天前我孩子理解了这道题：

【粘贴原题或描述题型】

请给我：
1. 一道同类型的变体题（换数字换人物，难度相当）
2. 一个"让孩子用自己的话解释"的引导问题（不直接问答案）
3. 判断标准：什么样的回答说明真的懂了，什么样的回答说明只是记住了答案

用于家长判断孩子是真会还是背会的。
```

## 模板五：睡前1分钟复述引导

**使用时机**：睡前，孩子说今天学的东西给你听。

```
我孩子今天学了【题型/具体题目简述】。

请给我3个递进的引导问题，用于睡前让孩子复述：
1. 第1个问题：回忆题目发生了什么（故事层面）
2. 第2个问题：说出关键步骤（思路层面）
3. 第3个问题：如果换成另一个情境，还是同样的想法吗（迁移层面）

问题语气要轻松，像聊天，不像考试。
```

**任务**:把 `mistakeNote/<年级>/<科目>/temp/` 下的素材整理归档为完整错题,产出物对齐已有三道样板:
- `二年级/数学/错题/2026-06-19-邮票一样多/`(React 复杂动效)

读 `mistakeNote/CLAUDE.md` 的"日常归档操作规约"和"互动版规则"两节作为基础,**别违反任何反目标**。

## 必须按这个顺序走,不许跳

### 1️⃣ 列素材 + 路径确认

- 跑 `ls -la mistakeNote/二年级/数学/temp/`(科目/年级如果不是二年级数学,从 temp 实际路径推断)
- 给我看清单,**逐项问我**:
  - 哪个是原题图?(→ 命名 `原题.png`)
  - 哪个是孩子的草稿照片?(→ 命名 `思路.png` 或 `思路2.png`)
  - 有没有 html / md 是 Claude 桌面版预生成的?(若有 = 模式 B / C,跳过对应生成步骤)
- **未确认前不要建文件夹**

### 2️⃣ 红线 1:强制三问(Jack 必须口述,Claude 绝不能编)

逐条问我,**全部得到回答前不要写 `<题目简称>.md` 的 `mistakes` 字段**:

> ① 孩子**原始**答案是什么(错的那个)?
> ② 草稿照片是**改正前** / **改正后** / **听讲后**才改的?
> ③ 谁提示他改对的(**自己醒** / **家长讲** / **老师讲**)?

把这三条揉成一句话写进 `mistakes[].note`,**不要扩写、不要润色出我没说过的细节**。

### 3️⃣ 读原题文字

从原题图提取题目原文(OCR / 看图)。**确认无误**(给我看抄出的文字,我点头再继续)。

### 4️⃣ 建文件夹 + 移素材

```
mistakeNote/<年级>/<科目>/错题/YYYY-MM-DD-$ARGUMENTS/
```

- 日期 = 今天
- 把 temp 素材 `mv`(不是 cp)到新目录,按命名约定改名
- 跑完 `ls` 让我确认文件齐了

### 5️⃣ 生成 `<$ARGUMENTS>.md`

文件名 = `$ARGUMENTS`(题目简称),例 `电影放映时长.md`。严格按 `mistakeNote/_system/模板/错题模板.md` 填:
- frontmatter:`status: 讲过`,`learned_at:` 留空,`next_review:` 今天 +3 天
- `mistakes` 字段 = 我口述的(红线 1)
- 题面区:题目原文 + 链 `打开.html` + 链 `<$ARGUMENTS>·变形.md`
- 家长区(`<details>` 折叠):错点分析 + 解题思路(CPA 三层,优先数形结合)+ 教学方法 + 复测安排 + 链 `<$ARGUMENTS>·变形.md`

### 6️⃣ 生成 `<$ARGUMENTS>·变形.md`

3 道梯度变形(参考三道样板的格式):
- 变形 1:**直接套用**,换数字
- 变形 2:**换方向 / 换条件**,核心抽象仍是原题考察点
- 变形 3:**进阶**,反向求 / 多变量 / 跨知识点
- 文末 `<details>` 折叠"家长专区 · 参考答案",含验算
- 题面区**不剧透提示词**(只在难题加 💡 一句)

### 7️⃣ 生成 打开.html(模式 A / B 时;模式 C 已给就直接用)

按 CLAUDE.md "互动版规则":
- **自包含离线**(无 `<script src=>`,无 `type="text/babel"`)
- 简单交互(按钮/计数/日历) → vanilla JS;复杂 SVG 动画/多步骤 → React 18 UMD 内联(JSX 预编译)
- 两个页签:`跟我学`(分步动画)+ `练一练`(随机题 + 即时判分 + ⭐ 反馈)
- 字号 ≥ 16px,触摸目标 ≥ 44px,**不要 AI 模板味**(紫渐变/三栏卡片/居中一切)
- 数形结合优先:线段图 / 数轴 / 日历 / 钟面 / 实物计数 / 拖动演示
- 底部加 `.parent-tip`:一句给家长的话(问孩子什么问题才知道他真懂)
- **复杂题一次成型可能不到位**,我看完会指出哪里不行,你迭代到位

### 8️⃣ 不要 commit

把 working tree 状态展示给我,**等我说"commit"再 commit**。三要素中文 commit:解决什么 + 方案 + 修改点。**不要 push**。

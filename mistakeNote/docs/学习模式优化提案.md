# childLearn 学习模式优化提案

> 状态：提案（待验证）  
> 日期：2026-09-10  
> 背景：结合 `mistakeNote` 现有北极星设计，以及外挂候选 OpenMAIC / DeepTutor，整理可落地的模式定义、改进流程与预期结果。  
> 约束：遵守 `CLAUDE.md` / `mistakeNote/Readme.md` —— local-first、文件是真相、先验证再自动化、孩子不碰 Claude/Obsidian、单次教学 ≤20 分钟、互动优先于长讲；Phase 0 未达触发条件前不写 web 前端、不接全自动 OCR API。

---

## 1. 这套模式是什么

**名称（工作称呼）：** 本地错题档案驱动的 CPA + 检索练习亲子教学

| 底座 | 含义 |
|---|---|
| Mastery / 错题闭环 | 只沉淀「栽过的题」，不堆题海 |
| CPA | 具体（实物）→ 图像（互动/线段）→ 抽象（算式）；适配视觉+动作型 |
| Retrieval + Spaced | 当天会不算会；D+3 / D+7 复测才算掌握 |
| Local-first 档案 | Markdown + 图 + Git 是长期资产；AI 只是视图/加速器 |

**外挂层（可选，不得反客为主）：**

| 层 | 工具 | 职责 |
|---|---|---|
| 真相层 | `childLearn` + Obsidian | 错题 MD、原题图、互动页、知识点双链、复测节奏 |
| 采集层 | `camera-capture` | 纸质 → `_inbox` |
| 讲解加速 | OpenMAIC（偶发） | 难讲的过程/动词题 → 短互动课；预审后陪看 |
| 辅导运行时 | DeepTutor 自托管（可选） | 限流陪练；**输出必须回流 mistakeNote** |

一句话：工程化亲子辅导操作系统，不是 AI 家教替代家长。

## 2. 现行流程（已跑通）

```
作业出错
 → 拍照台入库
 → （可选）rebuild-clean-exam
 → /新错题：家长确认真实错点（模型不许猜）
 → 互动版讲解 + 变形题
 → review_log：D+0 / D+3 / D+7
 → Obsidian 知识点反链 → 弱点地图
```

孩子入口：互动页、孩子模式重做。家长主控归档。

## 3. 建议改进（在原则内的轻量增强）

### 3.1 诊断先于讲解（+60 秒闸门）

归档后、做互动前，固定三问：

1. 用自己的话复述题目  
2. 卡在哪个词/动词  
3. 猜下一步会怎样  

复述错 → 先阅读理解，不先算。

### 3.2 课型分流（决定要不要上 AI 重武器）

| 题型 | 默认路径 |
|---|---|
| 过程/动词（送、比、倒推） | 互动 HTML → 必要时 OpenMAIC |
| 纯口算/格式 | 短练 + 错因标签，不上大模型课 |
| 概念首次出现（北师大新单元） | 课本例题 + 实物；错后再做互动 |

### 3.3 交错练习（Interleaving）

当日建议 3 题：**2 道本周弱点 + 1 道旧点混入**，避免 3 道同型。写入 `教学执行卡` 硬规则。

### 3.4 DeepTutor「回流协议」（若启用）

会话结束必须产出可归档字段：

- 题目简称  
- 错点（**家长确认**）  
- 是否新错题  

陪练机「答对」≠ `review_log` 打勾。以 D+3 / D+7 为准。

### 3.5 北师大进度白名单（防超纲）

教材：北师大版（非人教知识图谱对齐）。

每周维护 `本周单元.md`（课本页码 + 可讲知识点白名单）。AI 出题/讲解默认不得超白名单。

年级目录对称扩展（不推翻 schema）：

```text
mistakeNote/三年级/数学/
  教学库/
  错题/
  _复习/
```

笔记 frontmatter 建议增加：`textbook: 北师大`、`unit: …`。

### 3.6 阶段触发器（保持反目标）

| 阶段 | 触发条件 | 才允许做 |
|---|---|---|
| Phase 0 | 当前 | 积累错题 + 复测 |
| Phase 1 | ≥20 道错题且复测 ≥4 周 | 孩子模式列表/重做 UI |
| Phase 2 | grep 找题 >30s | 轻量筛选/看板 |
| 明确不做（现阶段） | — | 全自动 OCR 流水线、社交分享、成绩排名、过早 dashboard |

## 4. 目标与预期结果

### 4.1 对孩子（6–12 个月可观察）

| 目标 | 可预期 | 不预期 |
|---|---|---|
| 理解通道匹配 | 过程题更多靠互动看见变化 | 成绩碾压全班 |
| 元认知 | 能说出自己容易栽的题型 | 自学全自动 |
| 记忆 | D+7 通过率逐步升高 | 讲过当天永不忘 |
| 情绪 | 卡题少崩溃、敢说不会 | 零挫折 |

### 4.2 对家长

| 目标 | 可预期 |
|---|---|
| 时间 | 单题从长时间硬讲 → 采集归档约 5 分钟 + 讲解 ≤20 分钟 |
| 复习 | 期末按弱点地图抽题，不翻相册 |
| 资产 | 可跟到初中的私人方法学 + 错题图谱 |
| 关系 | 工具顶上硬讲，降低亲子摩擦 |

### 4.3 对系统（1–2 年）

- `三年级/数学`（北师大）目录对称长出；schema 被真实数据修正 ≥1 次  
- 出现「孩子要自己打开错题重做」信号（Readme 中的「毕业典礼」）  
- OpenMAIC / DeepTutor 可替换；搬走后档案仍完整  

### 4.4 明确不承诺

- 不替代学校与北师大课本进度  
- 不保证提分幅度（提分是副产品）  
- Phase 0 不追求产品完美

## 5. 建议的验证清单（给后续 AI / 人工）

请在不破坏 Phase 0 纪律的前提下验证：

1. [ ] `教学执行卡` 是否已包含：诊断三问、课型分流、交错练、20 分钟硬停  
2. [ ] 是否需要新增 `本周单元.md` 模板（北师大字段）  
3. [ ] 错题模板 frontmatter 是否应增加 `textbook` / `unit`  
4. [ ] `/新错题` 流程是否插入「诊断闸门」而不增加超过 1 分钟的负担  
5. [ ] 若引入 DeepTutor：回流字段与「家长确认错点」是否可无歧义执行  
6. [ ] OpenMAIC 使用边界：仅过程题、预审、要点写回该题 MD  
7. [ ] 确认不触碰：web 前端、全自动 OCR、成绩排名、把 vault 迁出 local-first  

**验证原则：** 先 propose 修改点 → 家长确认 → 再改；可用中文 commit；不主动 push（若工作流另有规定则从其规定）。

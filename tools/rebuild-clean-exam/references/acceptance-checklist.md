# 干净试卷交付验收清单

交付 PDF 前逐项确认。任何一项证据不足，都不能声称“题目准确”。

## 原始材料

- [ ] 已确认照片对应的逻辑页数、页序和正反面。
- [ ] 已保留原图，没有覆盖或删除事实来源。
- [ ] 已执行 `scripts/preflight.py`；依赖、字体和格式硬缺口已处理或明确列为阻塞，低分辨率 warning 已纳入置信度判断。
- [ ] 若使用 `scripts/clean_source_image.py`，已保留原图，并明确清理图只作为观察/OCR 辅助，不作为原题事实来源。
- [ ] 已生成 `questions.json`，每页记录了源图绝对路径、尺寸和 SHA-256。
- [ ] 已记录无法辨认或被遮挡的内容。
- [ ] 默认以用户图片为唯一题目依据，没有擅自联网反查或用其他版本替换图片内容。
- [ ] 若用户明确要求搜索原题，已记录反查结果并逐题核对版本；未要求则此项不适用。

## 内容准确性

- [ ] 每道题的题号、文字、数字、单位和标点已对照原图。
- [ ] 每道题在 `questions.json` 中有来源标记；上下文推断和用户确认没有混写。
- [ ] 选择题选项数量、顺序和图形语义正确。
- [ ] 钟表时间、图形轮廓、方格数量和按钮孔数正确。
- [ ] 没有把学生答案、姓名、班级或教师批改带入成品。
- [ ] 没有把推断内容伪装成已确认事实。
- [ ] 待确认项已经由用户确认，或明确列在交付说明中。

## 排版与可作答性

- [ ] 标题、正文、选项和页脚字号全卷一致。
- [ ] 题目之间、选项之间和并排小题之间有清晰间距。
- [ ] 选择题、判断题和计算题使用固定栅格，而非连续空格。
- [ ] 方框、圆圈、三角形和钟面数字在打印尺寸下清晰。
- [ ] 答题区域足够，不存在图文重叠或裁切。
- [ ] 没有孤行、拆词、句末两三个字单独成行。
- [ ] 图形为矢量或足够高分辨率，不模糊。

## PDF 技术检查

- [ ] 最终 PDF 位于项目相对目录 `outPdfFile/`，生成代码未写死用户绝对路径。
- [ ] 页数与预期一致。
- [ ] 纸张尺寸与要求一致；默认 A4。
- [ ] 中文字体和符号字体已嵌入。
- [ ] PDF 未加密，不含 JavaScript。
- [ ] 受影响页面已用 200-220 DPI 渲染检查。
- [ ] 全卷已用 150-170 DPI 重新渲染并逐页检查。
- [ ] 反向文字提取包含关键题干，不包含学生信息和答案。
- [ ] 若文本层提取存在 warning，已用渲染图逐页复核，未把 `--forbidden` 未命中当作充分证据。

## 交付说明

- [ ] 提供稳定、可点击的 PDF 文件。
- [ ] 提供对应 `questions.json` 路径，方便后续续作和 diff。
- [ ] 说明采用原卷、图像清理或矢量重建中的哪条路线。
- [ ] 汇报页数、纸张尺寸、字体嵌入和待确认项。
- [ ] 若用户提出版式修改，修改后重新执行全页回归，不只检查局部。
